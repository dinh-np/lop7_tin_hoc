### ### UI/UX Design System (Krones-Inspired)
* **Theme:** Corporate Light Theme (clean, spacious, industrial feel).
* **Typography:** `Noto Sans` (Primary) with `Georgia` fallback for excellent Vietnamese rendering.
* **Color Palette:** Krones Blue (`#0066AB`) as the primary accent, solid White (`#ffffff`) surfaces, and Light Gray (`#f8f9fa`) backgrounds. All legacy neon glows, glass-morphism, and gradient texts have been flattened into solid, high-contrast professional elements.
* **UI Rules:**
  - Crisp, solid borders (`border: 1px solid #e2e8f0`).
  - High contrast text (`#1a202c` for body, `#0066AB` for primary headers/buttons).
  - Spacious padding and clear visual hierarchy suitable for desktop and mobile touch devices.
  - Zero glassmorphism, zero neon glows, zero gradient text.

### CORE APP ARCHITECTURE & FEATURES

1. **Header & Navigation Bar:**
   - App Title: "Luyện Thi Tin Học 7 - Giữa Kỳ I"
   - PWA Install Button (Prompt user to install on Mobile/Desktop).
   - Mode Switcher: "Luyện Tập Theo Chủ Đề", "Thi Thử (45 Phút)", "Xem Câu Hỏi Sai".

2. **Mode 1: Luyện Tập (Practice Mode):**
   - Filter questions by Topic:
     * Chủ đề 1: Máy tính và cộng đồng (Thiết bị vào - ra, Phần mềm, Quản lý dữ liệu)
     * Chủ đề 2: Tổ chức lưu trữ, tìm kiếm và trao đổi thông tin (Mạng xã hội)
   - Show instantaneous feedback after choosing an option (Green for Correct `#22c55e`, Red for Incorrect `#ef4444`).
   - Display clear explanation/textbook reference based on Grade 7 Computer Science textbook (Kết nối tri thức).

3. **Mode 2: Thi Thử Ngẫu Nhiên (Mock Exam Mode):**
   - 30-40 questions randomly drawn from the 70-question bank.
   - Timer countdown (45 minutes).
   - Question palette grid for quick navigation between questions.
   - Final Submit button with summary modal: Score / 10, completion time, pass/fail evaluation, and option to review all attempted questions.

4. **Mode 3: Sổ Tay Cần Ôn Lại (Incorrect Answers Review):**
   - Automatically stores wrongly answered questions into `localStorage`.
   - Allows students to retake only the questions they previously answered incorrectly until mastered.

5. **PWA Capabilities:**
   - Full offline support via Service Worker (`sw.js`).
   - Web App Manifest (`manifest.json`) with app icons, theme color `#0066AB`.
   - LocalStorage synchronization to retain study progress and score history.
